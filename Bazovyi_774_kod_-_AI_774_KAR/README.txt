Arduino_A26.py - класс для обмена данными между бортовым компьютером и микроконтроллером.

SendCommand.py - пример управления перемещением беспилотника и обработки команд от микроконтроллера.
Используйте для подбора подходящей скорости.

LimitRangeRunner.py - программа для перемещения по дорожной разметке на заранее определённую дистанцию.
Используйте для ознакомления с алгоритмом детектирования разметки.

StadionRunner.py - программа для движения по дорожной разметки и остановки перед пешеходами.
Используйте для ознакомления инференсом нейросетевого детектора.

road_utils.py - файл с вспомогательными функциями для движения по дорожной разметке.

classes.txt - классы нейросетевого детектора.

yolo_uint8.tmfile - файл с моделью и весами детектора.

3-stage-encoder - прошивка для микроконтроллера. Представлена для ознакомления. 
Не меняйте прошивку без согласования с техническим экспертом.

quant_tool.py - скрипт для квантования модели yolo4-tiny для инференса на NPU беспилотника.
